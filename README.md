# StockPyme (nombre provisional)

App de gestión de inventario para pequeños comercios. Proyecto de práctica para el TFG de 2.º de DAM.

## Tecnologías previstas

| Parte | Tecnología |
|---|---|
| App móvil | Android con Kotlin |
| Backend | API REST con Spring Boot |
| Base de datos | Relacional, en un contenedor Docker |
